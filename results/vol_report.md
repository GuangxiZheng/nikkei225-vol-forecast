## 判定

1. **ボラティリティは予測できる（統計的に確立）**:
   HAR+VIモデルは市場指数(日経VI)をそのまま予測値として使うより有意に正確
   (二乗誤差差の95%CI [-24.5, -7.3]・全域負)。OOS R² = +0.34 は「予測可能な
   市場変数」として実在するシグナル(ロトの R²=0 とは対照的)。
   ただし優位の大部分は「VIの過大評価(リスクプレミアム)を補正する」効果で、
   HAR成分(過去ボラ)が独自に加える情報は小さい(+0.332→+0.342)。

2. **オプション売買で「安定して儲かる」は証明されない**:
   - 無条件VRP(常にshort): 前半 +106/年 → 後半(2023〜) +23/年。プレミアムは
     近年縮小しCIはゼロを含む。最悪週 −8,244ポイント
   - モデルtiming(τ=200): 前半 +237 → 後半 +118、CI [-102, 328] でゼロを含む
   - 最悪週: 2026-06-19 VI 29.9 → 実現 55.5 (−2,182ポイント)。
     short側は「小さな収入と、時々の壊滅的な損失」の構造

3. **実取引ではさらに劣化する**: バリアンススワップ近似のため、実オプションの
   スキュー(売る側が受取る下側リスク)・売買コスト・証拠金拘束は未反映

**結論**: 「予測できる」= Yes /「オプション売買で安定して儲かる」= 未証明。
