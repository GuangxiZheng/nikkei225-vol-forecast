## 採用判定 (事前宣言した基準)

採用には (1) 後半でのR²改善、(2) ΔMSEの95%CIがゼロを含まない、(3) 前半でも同方向、
の3点すべてが必要。1つでも欠ければ不採用とし、この結論は検証済み知見として残す。

- **V2 +pk5**: 後半改善 True / CI除外ゼロ True / 前半同方向 True → **採用候補**
- **V3 +dsr22**: 後半改善 True / CI除外ゼロ False / 前半同方向 True → **不採用**
- **V4 +maxz5**: 後半改善 True / CI除外ゼロ False / 前半同方向 True → **不採用**
- **V5 全部乗 (+3)**: 後半改善 True / CI除外ゼロ True / 前半同方向 True → **採用候補**
